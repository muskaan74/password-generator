# Password Generator 🔐

A simple Python application that generates secure and random passwords.

## Features
- Generates random passwords
- Uses letters, numbers, and special characters
- User can choose the password length
- Uses Python's `secrets` module for secure random generation

## Technologies Used
- Python
- `secrets` module
- `string` module

## How to Run

1. Clone this repository
2. Run the following command:
python password_generator.py
3. Enter the desired password length
4. Get your secure password 🔐
